    DPI metadata vs resampling

    Metadata-only mode keeps pixel dimensions and writes a new DPI value where the output format supports it. Physical-size mode resamples pixels so the printed size can stay consistent.

    Does 300 DPI improve quality?

    No. Writing “300 DPI” cannot invent missing detail. More pixels can be created by resampling, but that does not restore detail that was never captured.

    DPI and PPI

    PPI describes pixel density of digital images; DPI is commonly used by printers. Online forms often use “DPI” as shorthand for the image resolution metadata they expect.

    Frequently asked questions

    Can I convert an image to 300 DPI?

    Yes. Choose 300 DPI and select metadata-only or physical-size mode.

    Does 300 DPI make a blurry photo sharp?

    No. It changes density information or resamples pixels; it cannot recover lost detail.

    What formats can store DPI here?

    JPG and PNG output can carry DPI metadata. WebP workflows are better handled by physical-size resampling.
