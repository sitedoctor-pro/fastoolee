The result appears automatically after you choose an image. If DPI metadata is missing, Fastoolee reports that honestly instead of guessing.

What the checker reads

Fastoolee reports exact pixel dimensions, file size, format and embedded DPI metadata when it exists. It then estimates print size from pixels ÷ DPI.

What if DPI is missing?

Some images, especially web exports, contain no DPI metadata. The checker says “not embedded” rather than assuming a value.

Resolution is more than DPI

A 300 DPI label is meaningful only together with pixel dimensions and intended physical size. Always check all three.

Privacy & processing

The selected file is processed in your browser and is not uploaded to Fastoolee.

Frequently asked questions

How do I check image DPI?

Upload the image. The checker reads embedded DPI metadata immediately.

What if DPI metadata is missing?

The tool reports that it is missing instead of inventing a number.

Can I estimate print size?

Yes, when DPI exists: print inches = pixels ÷ DPI.
